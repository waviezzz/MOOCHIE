For this project, our team designed and developed a website using HTML and CSS for a company of our choice. We decided to create Moochie, a fictional dessert shop inspired by 
the beloved Japanese treat, mochi. The name is a cuter take on the original word "mochi," which fits the fun and playful vibe we intended for the brand. From the warm pastel 
color choices to the simple layout, everything is designed to create a cozy, welcoming feel and to be easy to navigate, especially for newcomers.
